```release-note:bug
provider: a read whose API call succeeds but returns no object (an empty page, a list that no longer contains the object, a soft-deleted entity, a nil payload) now removes the resource from state so the next plan recreates it, instead of leaving stale state or failing the plan. Affected: environment group, file store file and folder, resource group, role assignments, service account, every secret type, autostopping rules and schedules, cluster orchestrator config, variables, delegate token, environment service overrides, environment clusters mapping, GitOps repository certificates, chaos infrastructure (v1 and v2), IDP scorecards and checks, trigger pipeline executions, and the FirstGen delegate approval and user group permissions.
```

```release-note:breaking-change
resource/harness_platform_environment_service_overrides: the import ID now names the service as well as the environment, `[<org_id>/[<project_id>/]]<env_id>/<service_id>`. Importing by environment alone used to pick an arbitrary override of that environment.
```
