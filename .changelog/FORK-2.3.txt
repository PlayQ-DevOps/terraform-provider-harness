
```release-note:note
harness_platform_har_registry, harness_platform_har_lifecycle_rule, harness_platform_infra_provider_version, harness_platform_infra_provider_version_file, harness_platform_infra_provider_version_publish, harness_platform_idp_plugin: the importer no longer calls the API itself; Terraform reads the resource immediately after import as usual, so a non-existent object is reported by `terraform import` the same way as for every other resource.
```
